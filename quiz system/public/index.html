ACADEMIC LAB REPORT

Experiment #2: Timed Interactive Quiz App

Full-Stack Web Development, Asynchronous REST API Consumption, and LocalStorage Persistence.

1. Aim & Objectives

  • Build an interactive full-stack quiz web application with real-time countdown timers per question.
  • Asynchronously consume public REST APIs (Open Trivia DB `https://opentdb.com/api.php`) using JavaScript `fetch` and `async/await`.
  • Implement client-side data persistence using the Web `localStorage` API for profiles, active session state, and leaderboard history.
  • Construct a Node.js + Express.js backend proxy server providing sanitized REST endpoints and JSON data file persistence.
  • Integrate synthesized Web Audio API sound effects for interactive user feedback.

3. Key Concepts Explained

A. Asynchronous REST Consumption

Utilizes non-blocking JavaScript `async/await` and Promises to fetch remote JSON trivia objects. Includes HTML entity decoding (`"`, `'`) and fallback question bank fallback.

B. LocalStorage Persistence

Saves active quiz sessions so users can recover state on page refresh. Stores player profile, sound preferences, theme mode, and offline high scores.

C. High-Precision Timers

Executes a 100ms tick interval updating SVG `strokeDashoffset` circular rings, speed bonus multiplier calculations, and visual/audio urgency alerts.

D. Express Server & REST API

Node.js server provides dynamic API endpoints (`GET /api/quiz/questions`, `GET/POST /api/leaderboard`) with file-system persistence (`leaderboard.json`).

Result & Verification: All functional requirements verified — asynchronous API fetching, timer countdowns, streak scoring, audio synthesizer, local storage persistence, and leaderboard synchronization operate smoothly.
